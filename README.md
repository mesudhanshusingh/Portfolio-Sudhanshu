# 🚀 Sudhanshu Singh — Full Stack Developer Portfolio

A futuristic, high-performance, 4K cinematic portfolio website for **Sudhanshu Singh**, Full Stack Developer and Computer Science Engineering Student. Built with React, Vite, Tailwind CSS, and Framer Motion.

---

## 🌟 About The Project

This portfolio showcases Sudhanshu Singh's engineering projects, technical proficiency, education journey, internship experience, certifications, and contact information. It features a continuous deep dark canvas (`#020204`) illuminated by volumetric purple energy lighting, a realistic 3D developer hero portrait, and a floating glass island navigation header.

---

## ✨ Key Features

- **Futuristic 4K Cinematic Atmosphere**: Continuous pitch-black canvas (`#020204`) with saturated volumetric purple plasma energy beams and glowing HUD micro-interactions.
- **Realistic 3D Hero Portrait**: Chest-up 3D developer portrait rendered seamlessly without background containers.
- **Unique Floating Island Navigation**: Glass navigation header featuring active section indicators and a 2.5px spring-animated scroll progress bar.
- **Interactive Projects Showcase**: Interactive cards with HUD target corner reticles, light-sweep shimmers, and detailed project modals for SafeRide, AmbuRoute, and Offline UPI.
- **Interactive Internship Timeline**: Laser connector node timeline illustrating internship roles across AI, Web Development, JavaScript, and Python.
- **GPU-Accelerated 60 FPS Motion**: Built with Framer Motion and hardware-accelerated CSS transforms (`transform-gpu`) for buttery-smooth scrolling and zero-lag interactions.
- **Responsive Layout**: Tailored for Desktop, Tablet, and Mobile viewports.
- **Electric Cursor Effect**: Custom orange electric spark cursor trail and click particle burst.

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have **Node.js** (v18.0 or higher) installed on your system.

### Installation

1. **Clone or Navigate to Project Directory**:
   ```bash
   cd "New Portfolio"
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Launch Local Development Server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000/`.

---

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
```

The output will be generated inside the `dist/` directory, ready for deployment.

To preview the production build locally:

```bash
npm run preview
```
